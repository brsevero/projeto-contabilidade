COMO USAR A PLANILHA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Abra NexusTech_Atividades.xlsx no Excel (ou LibreOffice Calc).
  2. Leia a aba INSTRUCOES antes de começar.
  3. Use o PLANO_CONTAS para consultar os nomes exatos das contas.
  4. Preencha a aba LANCAMENTOS com os dados da SUA empresa
     (células em AZUL sobre fundo AMARELO = você deve preencher).
  5. A DRE, o BP e os Índices calculam automaticamente — mas você
     precisa preencher os valores nas abas DRE e BALANCO_PATRIMONIAL.
  6. Complete a aba ANALISE_E_GRAFICOS com sua interpretação.

  ATENÇÃO: Use os nomes das contas EXATAMENTE como estão no PLANO_CONTAS.
           Nomes diferentes farão os scripts Python não encontrarem os dados.

COMO USAR OS SCRIPTS PYTHON
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Pré-requisito: Python 3.8+ instalado  (python.org ou Anaconda)

  Instalar dependências (executar uma vez no terminal):
    pip install pandas openpyxl matplotlib fpdf2

  Executar na ordem (todos na mesma pasta que a planilha):
    python 01_importar.py      → lê a planilha, salva lancamentos_limpos.csv
    python 02_criar_db.py      → cria nexustech.db (banco SQLite)
    python 03_gerar_dre.py     → imprime a DRE no terminal
    python 04_gerar_bp.py      → imprime o Balanço Patrimonial
    python 05_calcular_indices.py → calcula e exibe os índices
    python 06_graficos.py      → gera graficos_nexustech.pdf/.png
    python 07_relatorio_pdf.py → gera relatorio_nexustech.pdf

  Dica: coloque todos os arquivos na mesma pasta antes de executar.
